バッテリー・充電 +
充電時間とバッテリーの寿命は？ +

満充電の目安は約6時間。寿命は約1〜2年。充電可能回数は300回前後が目安です。

雨の日でも使用できますか？ +

雨天時の走行、濡れた路面、水たまりでの使用は避けてください。暴風雪や極度の寒暖での運転回避、水をかけての冷却や洗車不可、雨天中の屋外・吹き込み場所での駐車による浸水リスク、ハンドルポストを畳んだ状態での水濡れ回避、水濡れ時はハンドルポストを立てて排水することを推奨します。
