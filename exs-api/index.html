STORY

デザインが良いモノは、高すぎる。
手頃なモノは、心躍らない。

eXs（エクス）は、ストリートカルチャーの自由な精神をルーツに持ちながら、日常に溶け込むデザインと実用性を両立する電動モビリティブランドです。

私たちの原点には、そんなジレンマを解決したいという想いがあります。
パーツサプライヤーとして長年培った経験と知識で、誰もが「気軽に、ラクに、そして楽しく」移動できる豊かな体験をお届けします。
